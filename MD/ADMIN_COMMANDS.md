# Админ-панель и операции

Документ для администраторов, которые управляют пулом подписок и сервисами.

## Доступ

- Админские функции доступны только Telegram ID из `ADMIN_IDS` в `.env`.
- Основной вход: кнопка `🔒 Admin Panel` в боте.

## Главное меню админки

| Раздел | Назначение |
|---|---|
| `📦 Инвентарь` | Добавление, чистка и обслуживание серверов |
| `📊 Статистика` | Состояние системы, пул подписок, регионы |
| `📢 Рассылка` | Сообщение всем или выбранным пользователям |
| `⚙️ Настройки` | Публичный домен, внешняя подписка и системные параметры |

## Инвентарь серверов

### Просмотр

```text
📦 Инвентарь -> список
```

Что видно:

- статус (активен/неактивен),
- пинг и технические метрики,
- регион/теги,
- базовые фильтры.

### Добавление

```text
📦 Инвентарь -> Добавить
```

Варианты импорта:

- одиночная ссылка,
- массовая загрузка (`.txt` со списком ссылок по одной в строке).

Поддерживаемые типы обычно включают `vless://`, `vmess://`, `trojan://`.

### Очистка и удаление

```text
📦 Инвентарь -> Удалить/Очистить
```

Типовые операции:

- удаление конкретной записи,
- очистка «мертвых» нод,
- очистка по региону/фильтру.

### Исправление

```text
📦 Инвентарь -> Исправить
```

Используется для массовой коррекции конфигов (например, после смены домена/SNI).

## Статистика

```text
📊 Статистика
```

Обычно содержит:

- количество пользователей,
- объем и качество активного пула,
- распределение по регионам,
- динамику доступности.

## Рассылка

```text
📢 Рассылка
```

Процесс:

1. Ввод текста.
2. Выбор аудитории.
3. Подтверждение отправки.

Рекомендуется делать короткие тексты и избегать частых массовых отправок, чтобы не упереться в rate limits.

## Админ-настройки

```text
⚙️ Настройки
```

Ключевые параметры:

- публичный домен/базовый URL,
- внешняя подписка (`EXTERNAL_SUB_URL`) для микса,
- сервисные флаги и режимы.
