# Команды администратора

## Доступ

Админ-панель доступна по кнопке **🔒 Admin Panel** в главном меню (только для `ADMIN_IDS` в конфиге).

---

## Главное меню админки

| Кнопка | Описание |
|--------|----------|
| 📦 Инвентарь | Управление сер 📊 Статистиверами |
|ка | Статистика системы |
| 📢 Рассылка | Отправить сообщение |
| ⚙️ Настройки | Настройки бота |

---

## Инвентарь (Управление серверами)

### Просмотр серверов
```
📦 Инвентарь → inventory_view
```

Показывает:
- Список серверов с пингом
- Фильтр по странам
- Статус (активен/мёртв)

### Добавление серверов
```
📦 Инвентарь → Добавить → inventory_add
```

Способы добавления:
1. **Ручной ввод** - вставить одну ссылку
2. **Массовый импорт** - загрузить текстовый файл

**Формат файла:**
```
vless://uuid@host:port?...
vmess://...
trojan://...
```

### Удаление серверов
```
📦 Инвентарь → Удалить → inventory_delete
```

Можно удалить:
- Конкретный сервер
- Все серверы страны
- Все мёртвые серверы

### Исправление
```
📦 Инвентарь → Исправить → inventory_fix
```

Восстановление работоспособности серверов после смены домена.

---

## Статистика

### Системная статистика
```
📊 Статистика → admin_stats
```

Показывает:
- Всего пользователей
- Активных пользователей
- Всего серверов
- Активных серверов
- Серверов по странам

---

## Рассылка

### Отправка сообщения
```
📢 Рассылка → broadcast
```

1. Введите текст сообщения
2. Бот разошлёт всем пользователям

**Опции:**
- Только активные пользователи
- Все пользователи

---

## Настройки

### Меню настроек
```
⚙️ Настройки → admin_settings
```

| Опция | Описание |
|-------|----------|
| Домен | Публичный домен для ссылок |
| Внешняя подписка | URL для микса |
| Проверка | Интервал проверки серверов |

---

## Управление через команды

Бот также поддерживает текстовые команды:

| Команда | Описание |
|---------|----------|
| `/stats` | Краткая статистика |
| `/broadcast <текст>` | Рассылка |
| `/add <ссылка>` | Добавить сервер |
| `/backup` | Скачать backup БД |
