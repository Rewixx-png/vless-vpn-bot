# Команды пользователя

## Главное меню

| Кнопка | Описание | Функция |
|--------|----------|----------|
| 🚀 Подключиться | Получить ссылку подписки | `my_subscription` |
| 📂 Мои Профили | Управление профилями | `groups_list` |
| 📡 Статус Сети | Статистика сети | `public_stats` |
| ⚙️ Настройки | Настройки подписки | `settings_main` |
| 📱 Приложения | Инструкции для приложений | `apps_menu` |
| 🆘 Помощь | Инструкция по подключению | `user_instruction` |
| 💎 Поддержать проект | Донат | `donate_info` |

---

## Подписка

### Получение ссылки
```
🚀 Подключиться → my_subscription
```

Показывает:
- URL подписки
- Кнопку "Открыть в FlClash"
- Инструкцию по настройке

### Группы профилей
```
📂 Мои Профили → groups_list
```

Возможности:
- Создание нового профиля
- Просмотр списка профилей
- Редактирование профиля
- Удаление профиля

Каждый профиль имеет:
- Название
- Фильтр стран
- Фильтр тегов

## Настройки

### Главное меню настроек
```
⚙️ Настройки → settings_main
```

| Опция | Описание |
|-------|----------|
| 🌎 Страны | Фильтр по странам |
| ⚡ Типы серверов | Фильтр по тегам |
| 🔢 Лимит серверов | Ограничение количества |

### Фильтр стран
```
⚙️ → Страны → settings_countries
```

Выбор стран для подписки. Можно выбрать несколько.

### Типы серверов (Теги)
```
⚙️ → Типы серверов → settings_tags
```

| Тег | Описание | Иконка |
|-----|----------|--------|
| Stable | Серверы с аптаймом 24ч+ | 🛡 |
| AI Ready | Для ChatGPT/Gemini | 🤖 |
| Low Latency | Пинг < 100ms | ⚡ |
| Reality/Vision | Скрытность | 👁 |

### Лимит серверов
```
⚙️ → Лимит серверов → settings_limit
```

Опции: 10, 50, 100, 200, Безлимит

## Донат

### Меню доната
```
💎 Поддержать проект → donate_info
```

Показывает способы оплаты:
- Криптовалюта (Crypto Pay)
- Карты РФ (Т-Банк)
- Райффайзен

### Процесс оплаты
```
donate_info → crypto_selection
```

1. Выбор суммы или ввод своей
2. Создание счета через CryptoBot
3. Оплата
4. Подтверждение (автоматическое)

## Статистика

### Публичная статистика
```
📡 Статус Сети → public_stats
```

Показывает:
- Общее количество серверов
- Количество по странам
- Лучший пинг

## Приложения

```
📱 Приложения → apps_menu
```

- v2rayNG (Android)
- Streisand (iOS)
- V2Box (iOS)
- FlClash (Android)

### Инструкция для приложения
```
📱 → [Выбор приложения]
```

Показывает:
- Ссылку для скачивания
- Инструкцию по настройке
- Deep Link для быстрого подключения
