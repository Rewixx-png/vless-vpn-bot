# Пользовательские сценарии

Документ описывает, что доступно обычному пользователю в Telegram-боте.

## Главное меню

| Кнопка | Что делает |
|---|---|
| `🚀 Подключиться` | Показывает персональную ссылку подписки |
| `📂 Мои профили` | Управление отдельными профилями/группами |
| `📡 Статус сети` | Публичная статистика и состояние пула серверов |
| `⚙️ Настройки` | Фильтры стран/тегов и лимит серверов |
| `📱 Приложения` | Инструкции по клиентам и подключению |
| `🆘 Помощь` | Базовый FAQ и шаги подключения |
| `💎 Поддержать проект` | Донат/поддержка проекта |

## Подключение

### 1) Получение подписки

Путь в интерфейсе:

```text
🚀 Подключиться
```

Пользователь получает:

- URL подписки,
- кнопку быстрого открытия в поддерживаемых клиентах,
- краткую инструкцию.

### 2) Использование профилей

Путь в интерфейсе:

```text
📂 Мои профили
```

Профили позволяют разделять подписку по сценариям (например, "Работа", "Стриминг", "Только DE").

Для каждого профиля можно настроить:

- название,
- фильтр стран,
- фильтр тегов,
- отдельную ссылку подписки.

## Настройки подписки

Путь в интерфейсе:

```text
⚙️ Настройки
```

Доступные параметры:

- `🌍 Страны` - какие регионы включать в подписку.
- `⚡ Типы серверов` - фильтр по тегам качества/назначения.
- `🔢 Лимит серверов` - ограничение количества выдаваемых нод.

Основные теги:

| Тег | Назначение |
|---|---|
| `Stable` | более стабильные узлы |
| `AI Ready` | узлы с доступом к AI-сервисам |
| `Low Latency` | низкая задержка |
| `Reality/Vision` | соответствующий тип конфигураций |

## Приложения

Путь в интерфейсе:

```text
📱 Приложения
```

В этом разделе:

- ссылки на рекомендуемые клиенты,
- краткие инструкции по импорту подписки,
- deep link (где поддерживается клиентом).

## Донат

Путь в интерфейсе:

```text
💎 Поддержать проект
```

Обычно включает:

- выбор суммы,
- создание счета (через CryptoBot/подключенные методы),
- автоматическую проверку оплаты.

## Типовой путь нового пользователя

```text
/start -> 🚀 Подключиться -> открыть ссылку в клиенте -> при необходимости настроить фильтры в ⚙️
```
