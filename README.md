# 🚀 VLESS VPN Telegram Bot

Мощный и быстрый Telegram бот для автоматической продажи и выдачи VLESS/VMESS/Trojan конфигураций.
Разработан на **Python 3.10+** с использованием **Aiogram 3.x** и **PostgreSQL**.

---

## ✨ Основные возможности

### 👤 Для Пользователей
*   📥 **Моментальная выдача:** Получение рабочей конфигурации в 2 клика.
*   🌍 **Выбор региона:** Автоматическое определение страны и флага сервера по IP.
*   ⚡️ **Умная сортировка:** Бот всегда выдает сервер с минимальным пингом (latency) в выбранном регионе.
*   💸 **Оплата:**
    *   **Автоматическая:** CryptoPay (USDT).
    *   **Ручная:** Вывод реквизитов карт.
*   📱 **Zero-Spam UI:** Интерфейс не засоряет чат, сообщения обновляются "на лету".

### 🛠 Для Администратора
*   🚀 **Скоростной Чекер (High-Performance):**
    *   Многопоточная проверка (50+ потоков).
    *   **Deep Check:** SSL Handshake + HTTP Request.
    *   Выявляет "зомби" серверы (Cloudflare EOF, 404, 502 ошибки), которые пингуются, но не работают.
*   📂 **Массовая загрузка:**
    *   Загрузка `.txt` файлов с тысячами ключей.
    *   Автоматический парсинг ссылок из текста.
*   📢 **Рассылка:** Отправка уведомлений всем пользователям (текст, фото, видео).
*   ♻️ **Управление базой:** Перепроверка всех подписок одной кнопкой и отключение нерабочих.

## ⚙️ Установка и Настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/vless-vpn-bot.git
cd vless-vpn-bot
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта и заполните его своими данными:

```ini
# Токен вашего бота от @BotFather
BOT_TOKEN=123456789:AAH...

# Список ID администраторов (числа через запятую)
ADMIN_IDS=[12345678, 87654321]

# Подключение к базе данных PostgreSQL
# Формат: postgresql+asyncpg://пользователь:пароль@хост/имя_базы
DB_URL=postgresql+asyncpg://vless_bot:StrongPass@127.0.0.1/vless_bot_db

# Токен приложения CryptoBot (для приема оплат в USDT)
CRYPTO_BOT_TOKEN=123456:AA...
```

### 3. Установка зависимостей
Рекомендуется использовать Python 3.10 или выше.
```bash
pip install -r requirements.txt
```

### 4. Инициализация базы данных
При первом запуске бот автоматически создаст необходимые таблицы в PostgreSQL.

## 🚀 Запуск в Production (PM2)

Для работы бота 24/7 используйте менеджер процессов **PM2**.

1.  **Установка PM2:**
    ```bash
    sudo apt update
    sudo apt install -y nodejs npm
    sudo npm install -g pm2
    ```

2.  **Запуск бота:**
    ```bash
    pm2 start bot.py --name "VPN" --interpreter python3
    ```

3.  **Полезные команды:**
    *   `pm2 logs VPN` — просмотр логов.
    *   `pm2 restart VPN` — перезагрузка.
    *   `pm2 save` — сохранение списка процессов.
    *   `pm2 startup` — настройка автозапуска при перезагрузке сервера.
